## Project Objective

The main objective is to analyze and model data related to **Employee Attrition**, i.e., the phenomenon of employees leaving the company. Specifically, the project aims to:

- Classify employees based on their likelihood of leaving (`Attrition`)
- Predict the level of **Work-Life Balance** using regression models

## Techniques Used

- **Preprocessing**: Encoding, normalization, train-test split
- **Classification Models**:
  - K-Nearest Neighbors (KNN)
  - Neural Network
- **Regression Models**:
  - Multiple Linear Regression
- **Evaluation Metrics**:
  - Accuracy, Precision, Recall, F1-score (for classification)
  - RMSE, MAE, R² (for regression)
